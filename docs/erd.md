# ERD

관계선의 라벨은 외래키 속성이다. `_cd` 속성의 `코드` 참조선은 `코드관계매핑` · `고유속성` 외에는 생략한다.

## 공간·층서

```mermaid

  "사업단위" |o--o{ "조사구역" : "조사ID"
  "조사구역" |o--o{ "조사구역" : "상위구역ID"
  "조사구역" |o--o{ "발굴구획" : "구역ID"
  "기준층위" |o--o{ "토층" : "기준층위ID"
  "토층" |o--o{ "혼입요소" : "토층ID"
  "토층" |o--o{ "층서관계" : "기준층서ID"
  "토층" |o--o{ "층서관계" : "대상층서ID"
  "발굴구획" |o--o{ "매핑_구획_기준층위" : "구획ID"
  "기준층위" |o--o{ "매핑_구획_기준층위" : "기준층위ID"
```
