# 코드그룹 목록 (Code groups)

접미사 `_cd` 를 가진 열은 모두 `코드.코드ID` 를 참조한다. 어느 코드그룹의 값이 허용되는지가 그 열의 도메인이며, 이 표는 30개 릴레이션이 참조하는 코드그룹 전부를 싣는다.

- **계층** — `코드.상위코드ID` 자기참조로 위계를 갖는 그룹(시소러스의 계층 관계). 값은 잎 마디뿐 아니라 상위 마디도 될 수 있다.
- **어휘 수** — 추출 시점(2026-09) 기준 활성 코드 수. 어휘는 코드 행을 추가하는 것만으로 늘어나므로 이 수는 스키마의 일부가 아니라 참고값이다.
- 코드 사이의 규칙(어느 분류에 어느 부위·문양·속성이 붙는가, 동의어·관련어)은 `코드관계매핑` 이 데이터로 지닌다.

## 시소러스와의 대응 (논문 표 4)

| 시소러스 관계 | 구현 |
|---|---|
| 계층 관계 | 코드.상위코드ID (자기참조) |
| 연관 관계 | 코드관계매핑 (기준 코드 – 대상 코드 – 관계유형 `…적용가능`) |
| 등가 관계 | 대표어만 적재하고, 코드관계매핑의 `동의어` · `관련어` 로 조회 시 접근 |
